# Containerization Class – 10 February

## Task: Multistage Docker Build for C Application

---

## Objective

To implement multistage Docker build to reduce image size.

---

## Description

In this experiment, a multistage Dockerfile was used to compile
the C program in one stage and run it in another stage.
This reduced the final image size and improved performance.
