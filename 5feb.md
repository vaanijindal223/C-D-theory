# Containerization Class – 5 February

## Task: Running Java Application Using Docker

---

## Objective

To create a Docker image for a Java application and execute it using Docker commands.

---

## Description

In this experiment, a Java program was containerized using Docker.
A Dockerfile was created to automate the build and execution process.
The image was built and run using different Docker commands, including
interactive mode for debugging.
